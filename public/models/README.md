Model folders for Vite-served GLB/GLTF assets.

- weapons: first-person weapon view models, e.g. `/models/weapons/rifle.glb`
- characters: player and bot character models, e.g. `/models/characters/player.glb`
- props: decorative map props, e.g. `/models/props/palm.glb`

Runtime paths should start with `/models/...`.
